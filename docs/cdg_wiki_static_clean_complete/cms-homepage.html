CMS Homepage

Pagina esportata da MediaWiki e resa come HTML statico.

In questa sezione l'amministratore potrà configurare i contenuti della Homepage della piattaforma nei diversi anni di budget attivi.

Accedendo alla scheda l'amministratore visualizzerà l'elenco dei contenuti inseriti.

Cliccando su "+ Aggiungi" potrà aggiungere un nuovo contenuto compilando gli appositi campi relativi alla tipologia di contenuto (HTML oppure file allegato), l'anno di inizio visualizzazione, l'anno di fine visualizzazione e l'ordine di visualizzazione nelle homepage degli anni di budget per i quali si attiva il contenuto.

Una volta inserito il nuovo contenuto occorrerà cliccare nella relativa riga che adesso comparirà in tabella per definire le caratteristiche del contenuto sulla base della tipologia selezionata. Nel caso di un file da allegare occorrerà inserire la descrizione del file e caricarlo mediante le funzionalità "Scegli file" e "Allega".

Nel caso di un contenuto HTML, invece, selezionando la relativa riga si avrà accesso all'editor di testo mediante il quale inserire il contenuto che si desidera visualizzare in homepage.
